# whisperMe v1.0.1 Release Notes

🎉 我们很高兴地发布 **whisperMe v1.0.1** 版本！本版本专注于优化本地模型部署与管理体验、精细化重构播放器与工作台 UI 交互，并修复了服务重启时的自动总结 Bug。

---

## 🚀 主要更新与新特性

### 1. ⚙️ 本地模型管理与配置精细化
*   **恢复 ASR / LLM 模式切换**：重新放开在设置页的引擎模式选择，用户可自由在“在线 API”与“本地模型”之间灵活一键切换。
*   **绝对路径默认化与自适应迁移**：放弃尴尬的相对路径，默认本地 ASR 路径现已改为绝对物理路径（项目内的 `models/funasr`）。系统启动时若检测到本地路径为空，将自动智能迁移至此绝对路径。
*   **跨平台原生文件夹选择器**：为本地 ASR 模型路径引入了原生文件系统目录选择按钮（📁 选择目录），完美适配 **Windows**、**macOS** 与 **Linux (Tkinter)**，用户无需再手动复制粘贴复杂的物理路径。
*   **在线/本地双重模型推荐**：设置页面内提供精挑细选的本地 ASR (FunASR/Whisper) 和 Ollama 本地模型 (Qwen 2.5) 的配置、拉取指引。

### 2. 🎨 工作台 (Workstation) 与卡片排版重构
*   **标题/节目分线排版**：全面优化了 Library 库和 Workstation 中网格卡片与列表行的文字换行排版。将小宇宙/网易云等播客“系列名称”与具体的“单集标题”拆分为上下两行展示（系列名称红字粗体、单集标题 truncate/line-clamp-2 截断限制），完美解决了超长标题导致的卡片参差不齐与布局挤压折行。

### 3. 🎯 详情页 AI 总结 Tab 交互精细化
*   **移出 Header 按钮**：详情页右上角的常驻“运行AI总结”按钮已移出，使界面更清爽。
*   **Tab 页内置与状态匹配**：运行 AI 总结的触发操作现在完全收纳在“AI总结” Tab 页下：
    *   *转录中/排队中*：按钮呈置灰状态，带有“⏳ 转录中，完成后可运行AI总结”的状态警示。
    *   *转录完成/失败*：点亮为红色醒目的“✨ 运行 AI 深度总结”按钮。
    *   *已有总结*：总结面板右上角提供“🔄 重新生成总结”功能，方便您在 Settings 调整模板或 Prompt 后重新跑分析。
*   **Prompt 弹窗体验重构**：统一了 Prompt 微调弹窗内的模板选择下拉框样式。编辑区域行高扩充至 `rows={22}`，并锁定了拉伸（`resize-none`），带来更好的编辑沉浸感。

### 4. 🤖 AI 总结防错约束
*   **自适应声纹分析降级**：在默认 AI 总结 Prompt 模板中增加了容错与防错约束指令。当播客任务在未开启声纹识别（即转录文本无 Speaker 区分）的情况下，AI 总结会自动跳过对特定发言人角度立场的拆解，但仍会完整提取并分析出节目中的核心观点与结论，避免总结逻辑发生崩塌。

---

## 🐛 缺陷修复与清理
*   **开机自动重排队 Bug 修复**：修复了服务器重启或启动时，会将“已转录但未总结”的任务 (`transcribed` 状态) 误判为“因异常中断的任务”重新拉入队列自动启动 AI 总结的缺陷。现在启动仅会扫描并恢复真正的 transient 状态（`pending`、`downloading`、`transcribing`、`summarizing`）。
*   **冗余清理**：清除了项目中不再维护的失效旧模块，并清理了 SQLite 数据库中废弃的旧数据表，使底层结构更加轻盈高效。

---

## 💾 1.0.1 绿色版打包发布形式
本版本提供单一的统一绿色分发包（如 `whisperMe-v1.0.1.zip`）：
- **开箱即用（在线模式）**：包大小轻量，解压即可运行，默认使用极速、无需任何本地大库的在线高精度 ASR API 和在线大模型进行总结。
- **平滑启用（本地模式）**：用户需要离线使用时，只需在设置页一键切换为“本地模型”，系统会在首次运行时自动在后台将推荐模型（如 Paraformer）静默拉取部署至软件内的 `models/` 目录下，无需手动下载与环境配置。若网络受限，亦可手动解压模型文件夹放入 `models/` 中。
